# 从一行题目追到一次评分
以下路径均相对于 lock.json 对应版本。文中“读到”指静态源码，“实测”限于 P0 调查日志中的操作。

**CVDP 给出题目、产物契约与裁判。** 本次选定 JSONL 的 input.prompt 和 input.context 描述问题并提供文件内容。output.context 的键给出目标文件名；即使目标内容为空，路径也有意义。harness.files 带 Compose 配置、测试、runner 和任务环境。run_benchmark.py 选择处理器，src/dataset_processor.py 的 CopilotProcessor 准备 Non-Agentic 题，Repository 执行 harness 并汇总测试。AgenticProcessor 处理另一种含顶层 prompt/context/patch/harness 的题型，可使用 agent 容器。两实验采用同一 Copilot 行，以目标路径上的最终内容为共同产物。[CVDP 源码](https://github.com/NVlabs/cvdp_benchmark/tree/8e894cf74414ab1eaea1e2b4e80a02f123df07b6/src)

**ACE 负责生成、反馈与再生成。** 阅读顺序为 skills/ace-rtl/scripts/ace_cvdp_native_runner.py → ace_cvdp_native/cli.py 的 run_attempt → llm.py 的 AceIterationModel → processor.prepare / processor.run。在每轮，生成器基于公开输入、上次候选及修复建议输出代码，提取步骤可能改写模型文本；应同时保存原文和实际受测文件。预检失败可先于仿真返回。失败后 FreshStartCoordinator 决定继续或重启，再按条件调用 Reflector。Coordinator 的决定可能来自规则；一个角色的 response.json 不对应固定一次模型调用。成功会停止同题其他尝试，因此默认多个 attempt 的成绩不等于一次独立运行的成功率。[运行循环](https://github.com/NVlabs/ACE-RTL/blob/94754d796350d42502c9a32639a20d86f50e9678/skills/ace-rtl/scripts/ace_cvdp_native/cli.py)

**供应商接入有两条路径。** llm_call.py 可经 ACE_RTL_LLM_SCRIPT 将 model、messages、temperature、top_p、max_tokens、stream、extra_body 以 JSON 传至 stdin，接收正文、content 或 Chat Completions 格式。另一条从 FocusedDebugger / FreshStartCoordinator → utils/llm_client.py → LLMBackend。后者在构造阶段按模型名检查 NVIDIA provider，即使外部脚本可用也需单独处理。P0 实测两个 DeepSeek ID 在内置后端构造时均报 ValueError。尚未实跑完整 ACE 启动。P1 先验证三角色路由与重试，必要时在共同 client/backend 增加窄范围 adapter 分支，保留 NVIDIA 路径。把每次真实请求的角色、消息、实际 model 和 usage 在调用边界记账，检查截断重试与流式末包，不从角色文件推算。[脚本入口](https://github.com/NVlabs/ACE-RTL/blob/94754d796350d42502c9a32639a20d86f50e9678/skills/ace-rtl/scripts/llm_call.py) · [内置后端](https://github.com/NVlabs/ACE-RTL/blob/94754d796350d42502c9a32639a20d86f50e9678/skills/ace-rtl/scripts/ace_rtl_agent/llm_backend.py)

**DSH 负责另一条求解轨迹。** 锁定源码 package.json 为 0.2.3-alpha.1。apps/cli 支持 headless 单任务；实验首选 Python SDK 的 DeepSeekHarness.run 和 RunResult.events/notifications，保存 session ID、独立 dsh_home 和对应 JSONL。SDK 的开发源码版本不是已发布 wheel 的可复现标识，实施时另锁 SDK/runtime 实际版本及配置 profile。不同 profile 改变工具集，应记录工具清单。DSH 获取同一 prompt 与 context 文件，写出同一路径的候选，由外部控制器提取并验收。sdk-minimal 的 shell 不限制 cwd 之外的访问，必须以真实的文件系统/进程隔离阻止访问数据集、评分器与凭据。对模型端和工具进程分别设置权限。[DSH SDK 使用说明](https://github.com/deepseek-ai/deepseek-harness/blob/d98f5d68519215da48f3002da2cb9c9d2068d81d/docs/user/guide/python-sdk.md) · [事件实现](https://github.com/deepseek-ai/deepseek-harness/blob/d98f5d68519215da48f3002da2cb9c9d2068d81d/python/sdk/src/deepseek_harness/api.py)

**验收信息会影响修复。** ACE 将同一行的 evaluator 结果回送，并在该判定通过时停止。RTL 目标的 build_reflector_harness_context 显式跳过 src 中 checker，但仍带服务定义和其他 RTL。Coordinator 持有 harness 路径且存在读取 src 中测试文件的条件路径；具体是否进入及实际传了哪些字节，要用真实请求审计。项目状态应标注“同测试反馈下成功”。进程外重新跑一遍同一套测试只能确认可重现性。result_passed 对 errors=0、tests 为空的结果存在 all([]) 为真的静态边界；目前未观察到该输入实际发生，应记录实际执行的测试数。[角色上下文](https://github.com/NVlabs/ACE-RTL/blob/94754d796350d42502c9a32639a20d86f50e9678/skills/ace-rtl/scripts/ace_cvdp_native/llm.py) · [判定函数](https://github.com/NVlabs/ACE-RTL/blob/94754d796350d42502c9a32639a20d86f50e9678/skills/ace-rtl/scripts/ace_cvdp_native/harness.py)

**外部证据。** CVDP 原论文的 783 道问题、13 类是论文口径；302 行是本次特定公开分区。ACE 论文研究专用和通用模型协作及并行搜索。NVIDIA 后续报告在九个类别给出 Nemotron 3 Ultra 97.1%、Kimi K2.6 95.2%、GLM 5.2 92.1% 的平均通过率。任务清单、聚合权重、尝试数、反馈权限、版本、单轮和总资源均影响比较。仅作方法和饱和风险参考，P0 自测模型任务数为零。[CVDP 论文](https://arxiv.org/abs/2506.14074) · [ACE 论文](https://arxiv.org/abs/2602.10218) · [NVIDIA 实验](https://developer.nvidia.com/blog/nvidia-nemotron-3-ultra-leads-open-models-on-accuracy-and-efficiency-in-agentic-rtl-coding/)
